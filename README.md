#  Simple Calculator

A clean, basic, and functional calculator web application built with **HTML**, **CSS**, and **JavaScript**. Perfect for everyday arithmetic operations.

##  Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Clear display and reset functionality
- Responsive design that works on desktop and mobile devices
- Real-time calculation as you type (or press buttons)
